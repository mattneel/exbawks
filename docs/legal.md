# Legal and Data Policy

Exbawks is an independent compatibility project.

Exbawks is not affiliated with Microsoft or Xbox.

## Repository data

Do not commit these items:

- Xbox BIOS or kernel images.
- Dashboard files.
- Game executables or assets.
- Encryption, signing, or console-unique keys.
- Proprietary SDK headers or libraries.
- Decompiled proprietary source code.
- Crash dumps that contain proprietary data.

## Local testing

Use software and data that you can lawfully access.

Keep private files in `fixtures/private` or another ignored directory.

Do not add automated downloads for copyrighted console files.

## Clean-room practice

Document public technical sources in `docs/references.md`.

Describe behavior and interfaces in original words.

Do not copy proprietary implementation code.

Keep compatibility tests synthetic when practical.
